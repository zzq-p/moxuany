# 消息、出餐、售后、菜单、收藏与员工

## 使用入口

| 功能 | 入口与规则 |
| --- | --- |
| 微信订阅消息 | 总后台「微信通知」保存接单、出餐/待取餐、退款结果模板。顾客在微信订单详情主动订阅。后台可查询待发送、成功、跳过、失败和结果不确定的记录。 |
| 出餐排队 | 后台「出餐排队」按店铺查看制作中及待接订单，支持接单、出餐；顾客订单显示前方单数与预计出餐时间。 |
| 售后举证与部分退款 | 顾客订单详情选择整单剩余退款或菜品数量，最多附3张JPEG/PNG照片。提交前由服务端计算可退金额并确认。店长在售后申请中查看照片和退款明细、审核并回复。 |
| 分时售卖与售罄 | 商品管理「一键售罄」「恢复售卖」「售卖时段」。最多4个北京时间段，支持跨午夜；售罄可指定恢复日期时间。 |
| 收藏与再来一单 | 店铺和菜品旁的星标；个人中心「我的收藏」；订单详情「再来一单」。 |
| 员工分工 | 「员工与记录」开通、停用及调整岗位，查看本店改价、库存、退款、核销、订单流转与员工管理记录。 |

## 退款与金额

仍使用本地模拟支付/退款，不产生真实资金交易。按原订单优惠后商品实付金额分摊到各份菜品，采用累计整数分摊保留每一分钱；分批退款合计不会超过实付。选中全部剩余菜品时自动变为整单剩余退款，配送费一并退回。

部分退款不结束订单，其余餐品继续履约。审核期间暂停流转。未制作时只回补所退份数及对应规格/加料库存；整单未制作退款才释放预约时段。已经制作的不回补库存。完成订单的积分按剩余实付计发，完成后退款撤回相应积分；销量按未退份数统计，经营报表和导出扣除全部已批准退款。

照片保存在上传目录同级的 `food-evidence` 私有目录，不通过公开 `/profile` 路径访问。仅订单本人或所属店铺有退款权限的员工能读取。单张上传不超过5MB且不超过1600万像素，每个订单累计最多12张；更换/重提申请可再次选择照片。

## 排队与售卖

店铺编辑中设置「并行制作」和「每单制作」时间，默认3单并行、每单15分钟。制作中订单优先，待接单按预约备餐时间（即时单按支付时间）排队；未到备餐时间的预约显示等待。首次支付记录原预计出餐时间，超时在厨房标红。估时仅针对出餐，不包含骑手路程，也不保证实际制作时间。

即时订单按当前北京时间校验菜品售卖时段，预约按所选用餐时间校验。售罄恢复采用时间判断，无需定时修改库存，不凭空补库存；实际库存为0时仍不能购买。购物车旧数据仍须在结算时重新校验。

「再来一单」读取原菜品及规格，按当前价格、库存、售卖状态重新整理；失效规格会移除，库存不足会减量。确认后替换购物车并进入结算，不自动支付，不沿用原预约日期、优惠券或地址。

## 员工权限

| 岗位 | 权限 |
| --- | --- |
| 店长 | 本店菜单/价格/库存、店铺设置、退款、评价回复、接单、出餐、核销、经营报表及员工管理 |
| 接单员 | 本店订单查看、接单、送达确认、取餐核销、评价回复 |
| 后厨 | 本店订单及排队查看、确认餐品备好 |

总后台可创建/调整店长，店长可管理接单员和后厨。禁止修改自己的岗位或停用自己，至少保留一位在职店长。后端每次读取在职岗位；旧登录会话不能绕过停用或降权。菜单变动需要重新登录。账号4至20位，初始密码10至20位，与现有登录校验一致。

## 微信配置

用户本轮确认尚无模板，交付范围为可配置链路，暂不启用真实发送。在本地 `.env` 设置以下字段，配置后重启后端；不要将AppSecret写入前端或提交到Git：

```dotenv
WECHAT_APPID=你的小程序AppID
WECHAT_SECRET=本地填写AppSecret
FOOD_SUBSCRIPTIONS_ENABLED=true
FOOD_MESSAGE_ENVIRONMENT=trial
```

`FOOD_MESSAGE_ENVIRONMENT` 支持 developer / trial / formal。总后台填写3个不同的模板编号及各自实际字段映射，例如 `{"thing1":"store","thing2":"status","time3":"time"}`。支持来源：store店铺、status状态、time事件时间、amount金额、order订单编号后32位、pickup取餐码。字段必须和微信公众平台模板一致，不可直接照抄示例。顾客须使用真实微信登录并在订单页点击订阅；演示账号不发送。

业务事务提交后，后台发送队列才处理通知；状态回滚不会留下待发送消息。同一业务事件只入队一次。明确失败的凭证/繁忙错误最多尝试3次；网络超时或进程中断的结果标为待核对，不自动重发。业务状态不因通知失败而回滚。

参考：[微信订阅消息API](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/mp-message-management/subscribe-message/sendMessage.html)、[腾讯云开发订阅消息指南](https://docs.cloudbase.net/en/recipes/add-subscribe-message-cloud-function)。真实模板字段、授权及消息送达需在微信开发者工具/真机进一步验证。
